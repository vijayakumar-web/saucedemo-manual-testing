\# SauceDemo E-commerce Manual Testing Project



\## 1. Project Overview



This project focuses on manual functional testing of the SauceDemo e-commerce demo website.



\*\*Application URL:\*\* https://www.saucedemo.com/



\*\*Testing Type:\*\* Manual Testing



\*\*Prepared By:\*\* Vijay



\## 2. Project Objective



To verify the core functionalities of an e-commerce application, including login, product listing, shopping cart operations, and checkout.



\## 3. Scope of Testing



The following functionalities are covered:



\- Login with valid credentials

\- Login with invalid credentials

\- Login with empty fields

\- Product listing verification

\- Adding a product to the cart

\- Removing a product from the cart

\- Checkout process

\- Order completion



\## 4. Test Environment



\- Operating System: Windows

\- Browser: Microsoft Edge or Google Chrome

\- Application: SauceDemo

\- Testing Method: Manual Functional Testing



\## 5. Test Cases



| Test Case ID | Test Scenario |

|---|---|

| TC001 | Login with Valid Credentials |

| TC002 | Login with Invalid Credentials |

| TC003 | Login with Empty Fields |

| TC004 | Verify Product Listing |

| TC005 | Add Product to Cart |

| TC006 | Remove Product from Cart |

| TC007 | Verify Checkout Process |

| TC008 | Complete Checkout |



\## 6. Testing Approach



1\. Open the application in a web browser.

2\. Execute the steps defined in each test case.

3\. Compare actual results with expected results.

4\. Record each test case status as Pass or Fail based on the observed behavior.

5\. Document any unexpected behavior for further investigation.



\## 7. Project Documents



\- `Test-Plan.txt` — Testing objectives, scope, environment, and approach.

\- `Test-Cases.txt` — Test scenarios, steps, expected results, actual results, and statuses.

\- `Test-Execution-Summary.txt` — Overview of test execution and results.



\## 8. Conclusion



This project demonstrates practical experience in manual testing fundamentals, test case preparation, test execution, and documentation for an e-commerce web application.
